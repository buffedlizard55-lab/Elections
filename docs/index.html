Project rules

1. Verified sources only — nothing enters the master list without a checked URL and evidence.  2. No hallucinations — no invented prices, polls, or results.  3. Official outcomes win — backtests score against certified results.  4. Flag, don't patch — anomalies go in the irregularities log with evidence.

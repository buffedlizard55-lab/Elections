Collector

Public endpoints only — no API key. Paginated, polite, fully logged. In CI it runs with --no-raw --compact --compact-max 2000 (independent sample; the Node collector in data/kalshi/universe/ is the complete record). Add --out-dir data/kalshi without --no-raw to keep raw responses locally.

python scripts/fetch_kalshi.py --out-dir data/kalshi --no-raw --compact --compact-max 2000 --series-file data/kalshi/universe/series.json
